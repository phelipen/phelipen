### Rodada 1 · O valor mudou?

```java
int pontos = 7;
System.out.println(pontos++);
```

<details>
<summary>A) Imprime 7</summary>

**Acertou!** O pós-incremento usa o valor atual na expressão e depois incrementa a variável. Ao final, `pontos` vale `8`.

</details>

<details>
<summary>B) Imprime 8</summary>

**Quase!** Esse seria o resultado de `++pontos`. Com `pontos++`, o valor usado na impressão ainda é `7`.

</details>

### Rodada 2 · Iguais em quê?

```java
String primeira = new String("Java");
String segunda = new String("Java");
System.out.println(primeira.equals(segunda));
```

<details>
<summary>A) Imprime false</summary>

**Tente de novo!** São objetos distintos, mas `String.equals()` compara o conteúdo. Usar `==` aqui resultaria em `false`.

</details>

<details>
<summary>B) Imprime true</summary>

**Acertou!** As duas strings contêm `Java`. O método `equals()` de `String` compara esse conteúdo.

</details>

### Rodada 3 · Cabe mais um?

```java
var linguagens = java.util.List.of("Java", "JavaScript");
linguagens.add("SQL");
System.out.println(linguagens.size());
```

<details>
<summary>A) Imprime 3</summary>

**Pegadinha!** `List.of()` cria uma lista que não permite modificações. A chamada a `add()` lança uma exceção antes da impressão.

</details>

<details>
<summary>B) Lança UnsupportedOperationException</summary>

**Acertou!** A lista criada por `List.of()` não permite adicionar elementos. Para isso, uma opção seria criar um `ArrayList` a partir dela.

</details>
